订单流程图

从对公选品下单到 OMS 履约、异常审核和售后退货

订单主链路
对公用户提交订单商品、数量、地址、邮编、快递公司
→
独立站创建本地订单保存用户、SKU、金额与收货信息
→
订单规则校验金额 / 首单 / 数量 / OMS库存锁定
未命中规则自动进入正常履约
创建 OMS 订单保存本地订单、OMS订单与包裹编号关系
↓
待分配仓库→待仓库拣货→待物流收揽→已发货
OMS异常状态商品缺货已关闭拦截发货成功
命中任一规则进入待审核
金额 > $5,000新用户首单数量 > 历史均值 3 倍OMS 库存锁定失败
审核通过重新发起库存锁定成功 → 待分配仓库失败 → 商品缺货
关闭订单填写关闭原因订单状态 → 已关闭
已发货订单用户可在“我的订单”查看详情
→
提交退货申请选择SKU、数量、原因和说明
→
退货规则判定未命中自动通过；命中则待人工审核
→
OMS与仓库处理收货、质检、换箱、入库或销毁
